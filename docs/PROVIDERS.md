# Providers

Set `provider` on an account to fill hosts, ports, and the OAuth token URL. You can still override any field.

| Provider        | IMAP                                     | SMTP                                     | Notes                                                                                                                                                                                                                                            |
| --------------- | ---------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `generic`       | you set the host, port 993, implicit TLS | you set the host, port 465, implicit TLS | Dovecot and Postfix submission. Sent mail is appended locally.                                                                                                                                                                                   |
| `gmail`         | `imap.gmail.com:993`                     | `smtp.gmail.com:465`                     | App password or OAuth. Token URL `https://oauth2.googleapis.com/token`, scope `https://mail.google.com/`. `appendSent: auto` does not APPEND, because Gmail stores Sent itself. Labels need `X-GM-EXT-1` (`mail_set_labels`, `gmraw`).           |
| `microsoft`     | `outlook.office365.com:993`              | `smtp.office365.com:587` STARTTLS        | OAuth is the usual choice. Token URL `https://login.microsoftonline.com/common/oauth2/v2.0/token`. Replace `common` with a tenant id via `auth.tokenUrl` when the tenant requires it. Scopes include IMAP and SMTP access plus `offline_access`. |
| `icloud`        | `imap.mail.me.com:993`                   | `smtp.mail.me.com:587` STARTTLS          | App-specific password. Username is the full iCloud address.                                                                                                                                                                                      |
| `fastmail`      | `imap.fastmail.com:993`                  | `smtp.fastmail.com:465`                  | App password. SPECIAL-USE, IDLE, and CONDSTORE are typical.                                                                                                                                                                                      |
| `yahoo`         | `imap.mail.yahoo.com:993`                | `smtp.mail.yahoo.com:465`                | App password when two-step verification is on.                                                                                                                                                                                                   |
| `proton-bridge` | `127.0.0.1:1143` STARTTLS                | `127.0.0.1:1025` STARTTLS                | The password is the Bridge password. Trust the certificate Bridge generated (`tls.caFile`) or, only for that local process, set `tls.rejectUnauthorized` to false.                                                                               |

Special-use folder names differ. The server prefers an explicit `sentMailbox` / `trashMailbox` / `draftsMailbox`, then SPECIAL-USE flags, then the names listed for that provider (for example Gmail `[Gmail]/Sent Mail` and Outlook `Sent Items`). `mail_resolve_special_use` shows which path was chosen and why.

OAuth client ids and secrets are created in the provider's developer console. This server only exchanges a refresh token; it does not run a browser login flow.
